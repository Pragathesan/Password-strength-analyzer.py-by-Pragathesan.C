# Password Checker by Pragathesan.C

This is a simple Python script that checks how strong your password is and gives feedback on how to improve it.

It also generates a random strong password if you need one.

## What it does

- Checks if password is at least 12 characters
- Checks for uppercase letters
- Checks for lowercase letters
- Checks for numbers
- Checks for symbols
- Detects common weak passwords
- Gives a strength score (weak, medium, strong)
- Suggests a strong password

## How to run

Make sure Python is installed on your system.

Run the file:
python "Password Checker ver1.0.py"

Then enter your password when asked.
